# ADR-031: governance-pipeline.ts を core/ から commands/ へ移動

## Status

Draft (auto-generated by ADR Auto-Draft Pipeline)

## Context

EP-0187 で導入された governance-pipeline.ts は scan → report のオーケストレーションを共有するために core/ に配置されたが、scan.ts と report.ts（commands/ 層）を import するため core-no-import-upper-layers ルールに 2 件違反する。

## Decision

governance-pipeline.ts を commands/ 層に移動する。このモジュールは scan + report を合成するオーケストレーターであり、summary.ts（health + delta + trend + triage の合成）や scan-demo.ts（scan + verify + report + health の合成）と同じ「コマンド合成」パターンに該当する。dependency-cruiser Rule 6 の from.pathNot に governance-pipeline.ts を追加し、合成ソースとして明示的に認可する。

## Consequences

governance-pipeline は core/ の public API から除外される。pitch-cli, health-cli, onboard-cli の import パスを ../core/ から ./ に変更する必要がある。外部パッケージ（shiori-vscode）が governance-pipeline を使用していないことを確認済み。
